每次发布新版本时，会自动发送以下信息：


### 邮件内容
1. **版本信息**
   - 版本号
   - 发布日期
   - 变更类型（功能/修复/优化）

2. **下载链接**

   - Linux 版本
   - Android 版本
   - macOS 版本
   - Windows 版本
   - iOS 版本

3. **更新日志**
   - 新增功能
   - Bug 修复
   - 性能优化
   - 已知问题

4. **测试报告**
   - 测试通过率
